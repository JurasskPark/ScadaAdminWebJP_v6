# Help and troubleshooting

[Contents](README.md) · [Русский](../ru/support.md)

## In-app help

Click **Support**, the lifebuoy icon in the top bar. **Help and support** opens
with links to documentation, the latest release, and the Russian and English
Rapid SCADA forums.

To find this editor guide, open the ScadaAdminWebJP repository and choose a
language on its home page. The driver link leads to separate materials.

## Common situations

| Situation | What to check |
|---|---|
| A project is missing from the list | Project directory settings, the `.rsproj` file, and application access to the server folder. |
| Some text remains in the previous language | Save documents, refresh the main page and reopen separate editors. Check buttons and column headings, not just the language list. |
| A device name remains in another language | It is project data. Switching the interface language does not rename records. |
| Table rows appear to be missing | Table search, column filters and the selected tree group; clear restrictions you do not need. |
| A filter field does not accept input | Click the field or focus it with Tab before entering a query. |
| Saving did not finish | The current editor's message, validation results and write permissions to the project directory. |
| A save command is disabled | Whether the document has changes and an editable document is selected. |
| A document opened on a separate page | The Tabs section of editor settings. |
| A theme or icon has not updated | Save the design setting and refresh the browser page. |
| The running system has not received edits | Saving and uploading are separate operations; check the deployment result. |

## Report a problem

Include the application version, language and theme, steps to reproduce,
and expected and actual results. Attach a screenshot of the relevant area
and the error text. Remove passwords, keys and other private data before sending.
