# ScadaAdminWebJP

**Web Administrator for Rapid SCADA · Веб-администратор Rapid SCADA**

Create and edit Rapid SCADA projects in a browser: configuration database tables,
project files, editor settings and configuration deployment.

Создавайте и редактируйте проекты Rapid SCADA в браузере: таблицы базы
конфигурации, файлы проекта, настройки редактора и развёртывание конфигурации.
